# DefiLlama 원천 참고 배수

2026-10-11부터 기본 표의 P/R·P/HR은 화면에 표시한 DefiLlama 원천 금액으로 계산하는 참고값이다. 수익 분류·귀속·실행 검토 결과는 별도로 표시한다.

- P/R: 현재 유통 시총 또는 FDV ÷ Revenue 연환산액.
- P/HR: 현재 유통 시총 또는 FDV ÷ Holders Revenue 연환산액.
- 1·7·30·90일: 원천 금액 × 365 ÷ 일수. 1년은 표시한 원천 1년 금액을 그대로 사용한다.
- 완전한 일별 이력이 있으면 완료 UTC 합계를 사용한다. 일별 이력이 부족하면 제공처의 전체 기간 합계를 사용하고 `제공처 집계`로 표시한다. 제공처 1년 합계는 `원천 1년`으로 표시하며, 365일 확보나 TTM을 보장하지 않는다.
- 수익 분류가 미확정이거나 검토 대기 중이어도 참고 배수를 계산한다. 원천 금액을 회사 매출·순이익·일반 보유자 현금 지급액으로 확정하지 않는다.
- 토큰 미연결, 스테이블코인 자본, 분자 미확인, 원천 금액 0 이하와 일부 구성요소만 확보한 합계는 계산하지 않는다. FDV를 유통 시총으로 대체하지 않는다.
- 저장된 환원 일별 이력이 검토된 일부 구성만 포함하면 전체 원천의 이력으로 사용하지 않는다. 전체 30일·1년 원천 합계가 있으면 그 금액으로 참고 배수를 계산한다. 확보하지 못한 다른 기간을 역산하지 않는다.

`lib/referenceMetrics.ts`가 금액 선택과 참고 배수 계산을 담당한다. 표·상세·정렬·필터·계산 가능 범위·내보내기가 같은 함수를 사용한다. 기간별 수익 표시와 분모는 `revenueReading()`의 같은 값을 사용한다.

API의 `referenceMultiples`는 반환된 각 종목의 선택한 시총 기준 참고 배수다. 수집본의 `coins[].multiples`와 기존 실험 점수는 당시 검토 기반 판정으로 보존한다. 참고값을 검토된 점수의 입력으로 승격하지 않는다. 증가율도 검토된 동일 기간 자료가 필요하다.

이 변경은 저장된 금융 자료·원천 응답·경제 검토 원장을 수정하지 않는다. 기존 공개본을 읽어 즉시 참고 배수를 산출하므로 재수집이나 검토 대기 해제가 필요하지 않다. API 보관소 감사는 원본 수집본의 해시를 그대로 검증하고, 요청 시 생성한 참고값을 별도로 대조한다.

재발 방지 검사는 검토 미확정, 최신 UTC 하루 누락, 제공처 1년, 부분 집계, 혼합 환원 구성, 시총·FDV 결측, 0·음수와 저장 설정을 다룬다. 원천 금액이 바뀌지 않는 한 분류 검토 상태나 일별 이력 부족만으로 참고 배수가 사라지지 않아야 한다. 제공처 조회 장애와 원천 금액 자체의 결측은 별도로 표시한다.

## 시세 연결과 계산 검증

시장 수집 revision 5부터 CMC 자산은 계약 주소, 충돌이 없는 명시적 숫자 ID, 전체 목록에서 유일한 정식 이름으로 연결한다. 제공처마다 slug가 같다는 이유로 같은 토큰으로 판단하지 않는다. EVM 주소는 대소문자를 구분하지 않고, Solana 주소와 Sui 자산 식별자의 대소문자·전체 문자열은 보존한다.

명시적으로 연결된 CoinGecko 시세를 우선 사용한다. CoinGecko에 양수 유통 시총이 없고 검증된 CMC에 있으면 CMC 가격·공급량을 함께 사용한다. 조회에 실패하거나 일부 필드가 없으면 검증된 제공처의 현재 값을 사용한다. 비활성 CMC 자산과 기준일이 수집 시각보다 12시간 넘게 오래된 시세는 계산에서 제외하고 사유를 표시한다.

FDV가 유통 시총보다 5% 넘게 작거나, 가격 × 유통량과 시총의 차이가 1.25배를 넘으면 해당 금액을 보류한다. 두 경계는 제공처의 반올림·관측 시각 차이를 허용하는 검증 기준이다. 가격 0에 양수 시총·FDV가 붙거나 시세 금액이 음수인 응답도 보류한다. 원천 공급량이나 시총을 임의의 배율로 고치지 않는다. 계약으로 연결되지 않은 구성상품의 가치를 상위 프로젝트의 가치로 사용하지 않는다.

새 수집본은 공개 전과 공개 후에 가격·유통량·시총·FDV를 검사한다. 전체 종목의 1·7·30·90·365일 P/R·P/HR을 유통 시총과 FDV 양쪽에서 독립적인 산식으로 대조한다. 양수 참고 배수가 0.01배보다 작으면 `<0.01x`로 표시한다. 과거 원천 응답과 공개본은 원래 revision으로 재현하며, 시세 수정은 새 수집본에 반영한다.
